# Sarjy Frontend

The frontend for **Sarjy**, a voice-first AI assistant built to help users discover artworks through natural conversation.

## Tech Stack

* Next.js
* React and TypeScript
* Tailwind CSS
* LiveKit for real-time voice interaction

## Prerequisites

* [Node.js](https://nodejs.org/)
* [Yarn](https://yarnpkg.com/)

## Getting Started

1. Clone the repository and navigate to the frontend directory:

   ```bash
   git clone https://github.com/Somaiya-XI/sarjy.git
   cd sarjy/front-end
   ```

2. Install dependencies:

   ```bash
   yarn install
   ```

3. Start the development server:

   ```bash
   yarn dev
   ```

4. Open http://localhost:3000.

## Available Scripts

| Command      | Description                  |
| ------------ | ---------------------------- |
| `yarn dev`   | Start the development server |
| `yarn build` | Build for production         |
| `yarn start` | Start the production server  |
| `yarn lint`  | Run ESLint                   |
